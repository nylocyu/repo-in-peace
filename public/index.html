AI epitaphs

With your own Claude API key, Claude reads the README and recent commits of each repo in your cemetery and writes its obituary and cause of death. That content is sent to the Anthropic API with your key; only the result is stored. Without a key you get the repo description and a random cause.

Private repos missing? Grant the app read-only access, then sync again.
